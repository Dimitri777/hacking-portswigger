# HTTP Host Header Attacks

Решения лабораторных работ PortSwigger Web Security Academy по теме HTTP Host header attacks.

## Содержание

Материалы и пошаговые решения лабораторных работ будут добавляться сюда по мере прохождения.

## Основные направления проверки

- Необработанное доверие к заголовку `Host`.
- Password reset poisoning.
- Обход проверок маршрутизации и контроля доступа.
- Cache poisoning и использование альтернативных заголовков, например `X-Forwarded-Host`.
