# Server-side Template Injection (SSTI)

Решения лабораторных работ PortSwigger Web Security Academy по теме Server-side Template Injection.

## Содержание

Материалы и пошаговые решения лабораторных работ будут добавляться сюда по мере прохождения.

## Методика

1. Найти место, где пользовательский ввод попадает в шаблон.
2. Определить движок шаблонов и контекст вычисления.
3. Проверить, интерпретируется ли ввод как выражение шаблонизатора.
4. По возможности использовать безопасные диагностические выражения; затем выполнить предусмотренную лабораторией цепочку эксплуатации.
