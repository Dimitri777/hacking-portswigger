## Как пользоваться чек-листом

По каждому пункту отметьте статус соответствия («да» / «нет» / «частично») и при необходимости внесите комментарий: ссылку на документ-основание, дату устранения несоответствия или ответственного за исправление. Пункты, отмеченные «нет» или «частично», формируют план устранения несоответствий.

Документ носит справочный характер, отражает общие требования 152-ФЗ и связанных подзаконных актов и не заменяет консультацию юриста или специалиста по защите информации — состав мер зависит от специфики деятельности, категорий и объёма обрабатываемых данных.

## 1. Общие сведения об операторе

Базовая идентификация организации как оператора персональных данных.

| № | Пункт проверки | Соответствие (да / нет / частично) | Комментарий / основание |
|---|----------------|------------------------------------|-------------------------|
| 1 | Организация определена как оператор ПДн (собирает, хранит или иным образом обрабатывает ПДн клиентов, сотрудников, партнёров) | ☐ да ☐ нет ☐ частично | |
| 2 | Организация зарегистрирована в реестре операторов персональных данных Роскомнадзора (уведомление об обработке подано) | ☐ да ☐ нет ☐ частично | |
| 3 | Сведения в уведомлении Роскомнадзора актуальны (цели обработки, категории субъектов, перечень действий с ПДн, сроки обработки соответствуют фактической деятельности) | ☐ да ☐ нет ☐ частично | |
| 4 | Назначено ответственное лицо за организацию обработки персональных данных (приказ о назначении) | ☐ да ☐ нет ☐ частично | |
| 5 | Определён перечень лиц, допущенных к обработке ПДн (приказ / список) | ☐ да ☐ нет ☐ частично | |

## 2. Правовые основания обработки

Проверка того, что каждая категория обрабатываемых данных имеет законное основание.

| № | Пункт проверки | Соответствие (да / нет / частично) | Комментарий / основание |
|---|----------------|------------------------------------|-------------------------|
| 1 | Для каждой цели обработки определено и задокументировано правовое основание (согласие, договор, закон и т.д.) | ☐ да ☐ нет ☐ частично | |
| 2 | Обработка специальных категорий ПДн (здоровье, биометрия и др.) имеет отдельное законное основание и повышенные меры защиты | ☐ да ☐ нет ☐ частично | |
| 3 | Обработка биометрических персональных данных (при наличии) соответствует требованиям о размещении в Единой биометрической системе, где применимо | ☐ да ☐ нет ☐ частично | |
| 4 | Обработка ПДн несовершеннолетних (при наличии) осуществляется с согласия законных представителей | ☐ да ☐ нет ☐ частично | |
| 5 | Отсутствует обработка ПДн сверх целей, заявленных в уведомлении Роскомнадзора и политике обработки | ☐ да ☐ нет ☐ частично | |

## 3. Согласия на обработку персональных данных

С 1 сентября 2022 года согласие должно быть конкретным, предметным, информированным, сознательным и однозначным. С 1 сентября 2025 г. — оформляется отдельным документом.

| № | Пункт проверки | Соответствие (да / нет / частично) | Комментарий / основание |
|---|----------------|------------------------------------|-------------------------|
| 1 | Форма согласия содержит все обязательные реквизиты (ст. 9 152-ФЗ): ФИО и адрес субъекта, наименование и адрес оператора, цель обработки, перечень действий, срок действия и порядок отзыва | ☐ да ☐ нет ☐ частично | |
| 2 | Согласие является предметным — соответствует конкретной заявленной цели обработки | ☐ да ☐ нет ☐ частично | |
| 3 | Согласие получено ДО начала обработки, а не постфактум | ☐ да ☐ нет ☐ частично | |
| 4 | Предусмотрен и реально работает механизм отзыва согласия субъектом | ☐ да ☐ нет ☐ частично | |
| 5 | Согласие на распространение ПДн (если данные публикуются/передаются третьим лицам) оформлено отдельным документом по установленной форме | ☐ да ☐ нет ☐ частично | |
| 6 | Согласия на использование cookie / метрических систем на сайте оформлены корректно, есть баннер и возможность отказа | ☐ да ☐ нет ☐ частично | |
| 7 | Хранятся доказательства получения согласия (чек-боксы, подписанные бланки, логи с сайта) на случай проверки | ☐ да ☐ нет ☐ частично | |

## 5. Локализация и трансграничная передача данных

Ч. 5 ст. 18 152-ФЗ: сбор, запись, систематизация, накопление, хранение, уточнение и извлечение ПДн граждан РФ должны производиться с использованием баз данных, расположенных на территории РФ.

| № | Пункт проверки | Соответствие (да / нет / частично) | Комментарий / основание |
|---|----------------|------------------------------------|-------------------------|
| 1 | Первичный сбор и хранение ПДн граждан РФ осуществляется на серверах, физически расположенных на территории РФ | ☐ да ☐ нет ☐ частично | |
| 2 | Формы сбора данных на сайте/в приложении не отправляют данные напрямую на иностранные серверы до записи в российскую базу | ☐ да ☐ нет ☐ частично | |
| 3 | При использовании зарубежных сервисов (CRM, аналитика, рассылки, облачные хранилища) проведена проверка на предмет требований локализации | ☐ да ☐ нет ☐ частично | |
| 4 | Трансграничная передача ПДн (если осуществляется) соответствует требованиям ст. 12 152-ФЗ, включая уведомление Роскомнадзора о трансграничной передаче | ☐ да ☐ нет ☐ частично | |
| 5 | Проверен актуальный перечень государств, обеспечивающих адекватную защиту прав субъектов ПДн, при передаче данных за рубеж | ☐ да ☐ нет ☐ частично | |

## 6. Технические и организационные меры защиты

Требования 152-ФЗ, Постановления Правительства РФ № 1119 и приказов ФСТЭК/ФСБ по составу мер.

| № | Пункт проверки | Соответствие (да / нет / частично) | Комментарий / основание |
|---|----------------|------------------------------------|-------------------------|
| 1 | Определён уровень защищённости ИСПДн в соответствии с ПП РФ № 1119 | ☐ да ☐ нет ☐ частично | |
| 2 | Реализованы организационные меры: разграничение доступа, учёт носителей ПДн, контроль допуска в помещения с ИСПДн | ☐ да ☐ нет ☐ частично | |
| 3 | Реализованы технические меры: антивирусная защита, межсетевое экранирование, средства обнаружения вторжений | ☐ да ☐ нет ☐ частично | |
| 4 | Используются сертифицированные (при необходимости) средства защиты информации и криптографии | ☐ да ☐ нет ☐ частично | |
| 5 | Ведётся журнал учёта действий с ПДн (кто, когда, какие действия совершал) в информационных системах | ☐ да ☐ нет ☐ частично | |
| 6 | Настроено резервное копирование и предусмотрен план восстановления после инцидентов | ☐ да ☐ нет ☐ частично | |
| 7 | Пароли, права доступа и учётные записи сотрудников, уволенных/сменивших должность, своевременно отзываются | ☐ да ☐ нет ☐ частично | |
| 8 | Проведена (или запланирована) периодическая оценка эффективности принимаемых мер защиты ПДн | ☐ да ☐ нет ☐ частично | |

Порядок и сроки уведомления Роскомнадзора об инцидентах, установленные 152-ФЗ.

| № | Пункт проверки | Соответствие (да / нет / частично) | Комментарий / основание |
|---|----------------|------------------------------------|-------------------------|
| 1 | Разработан и доведён до сотрудников план действий при обнаружении утечки/инцидента с ПДн | ☐ да ☐ нет ☐ частично | |
| 2 | Обеспечена техническая возможность оперативно зафиксировать факт и масштаб утечки (логи, мониторинг) | ☐ да ☐ нет ☐ частично | |
| 3 | Предусмотрено уведомление Роскомнадзора о произошедшем инциденте в течение 24 часов с момента обнаружения (первичное уведомление) | ☐ да ☐ нет ☐ частично | |

| 5 | Определён порядок информирования затронутых субъектов ПДн об утечке их данных, если это требуется по существу инцидента | ☐ да ☐ нет ☐ частично | |
