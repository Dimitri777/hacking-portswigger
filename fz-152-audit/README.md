## Что ещё рекомендуется добавить (в зависимости от деятельности)

**Обязательно почти для всех:**
1. Уведомление Роскомнадзора + актуальная выписка из реестра операторов
2. Акт определения уровня защищённости ИСПДн (по ПП РФ № 1119)
3. Договоры с подрядчиками, содержащие условия поручения обработки ПДн (ст. 6)
4. Документы по локализации (подтверждение размещения баз в РФ)

**При наличии специальных категорий / биометрии:**
- Отдельные согласия
- Дополнительные меры защиты
- Документы по Единой биометрической системе (если применимо)

**Для сайта:**
- Политика cookie + баннер с возможностью отказа
- Политика конфиденциальности (можно объединить с Политикой обработки ПДн)

**Кадровый блок:**
- Согласия работников на обработку ПДн, не связанных с трудовым договором
- Порядок хранения и уничтожения кадровых документов

## Как пользоваться пакетом

1. Пройдите [чек-лист](01-checklist-audit-152fz.md) — отметьте «да / нет / частично».
2. По пунктам «нет» и «частично» сформируйте план устранения.
3. Заполните и утвердите недостающие документы.
4. Адаптируйте шаблоны под свою организацию (цели обработки, категории субъектов, ИСПДн).
5. Ознакомьте работников под подпись.
6. Разместите Политику на сайте.

> **Важно:** Документы носят справочный характер и не заменяют консультацию юриста / специалиста по защите информации. Состав мер зависит от специфики деятельности, категорий и объёма обрабатываемых данных.

## Ответственность
Нарушения 152-ФЗ квалифицируются по ст. 13.11 КоАП РФ. Штрафы по отдельным составам достигают сотен тысяч / миллионов рублей, при повторных нарушениях — существенно выше. Роскомнадзор проводит внеплановые проверки.
