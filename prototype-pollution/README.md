# Prototype Pollution

Решения лабораторных работ PortSwigger Web Security Academy по теме Prototype Pollution.

## Содержание

Материалы и пошаговые решения лабораторных работ будут добавляться сюда по мере прохождения.

## Методика

1. Найти источник загрязнения (source), например небезопасное объединение объектов или запись в `__proto__`.
2. Определить, какие свойства попадают в прототип.
3. Найти gadget — участок приложения, поведение которого меняется из-за загрязнённого свойства.
4. Проверить влияние на клиентскую или серверную логику и выполнить лабораторную работу.
